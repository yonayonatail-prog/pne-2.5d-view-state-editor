# 看守 2.5D立ち絵モデル 人間作業手順書

## この手順書の範囲

この手順書では、人間がBlender上で行う作業だけを扱います。

人間が担当するのは、見た目の判断と関節の支点決めです。素材の読み込み、名前付け、ボーン生成、JSON・GLB・Atlasの出力、検証は後工程のツールに任せます。

この作業の完了条件は、次の2つです。

- `mihon.png` と見比べて、各パーツの配置・大きさ・重なり順が確定している
- 肩・肘・手首・首・髪の根元など、動かすための支点が確定している

## 最初に守ること

- 現在の手修正版を保存してから作業する
- `C:\works\2.5D\tools\build_kanshu_2_5d.py` は実行しない
- 既存の仮ボーンは編集せず、必要なら非表示にする
- 素材のPNGやKRAは変更しない
- オブジェクト名、親子関係、コレクション名は変更しない
- `Ctrl+A` の「トランスフォームを適用」は使わない
- JSONやGLBを手で編集しない

現在の手修正版を残すため、最初にBlenderで「名前を付けて保存」を行う。

推奨保存先：

`C:\works\2.5D\asset\model_kanshu\kanshu_2_5d_authoring.blend`

## 1. Blenderを配置確認用にする

1. `kanshu_2_5d_authoring.blend` を開く。
2. カメラビュー、またはキャラクター正面の正投影ビューにする。
3. `Kanshu_Reference` コレクションを表示する。
4. `mihon_reference` を表示し、実際のキャラクターと重ねて比較できるようにする。
5. 仮ボーンが見づらければ、`kanshu_armature` を非表示にする。
6. 配置作業は静止状態で行う。アニメーションの途中のフレームで調整しない。

正面から見たときの座標は次の扱いです。

- 左右：X軸
- 上下：Z軸
- 前後：Y軸
- カメラは -Y 側
- 前面に出すパーツは、既存の重なり順を崩さない範囲でYを少し負方向にする

Y座標は大きく動かさず、髪・顔・目・口の重なりが正しく見えることを優先する。

## 2. 配置を調整する順番

全体から細部へ進める。最初から目や口を合わせない。

### 2-1. 胴体

次の順番で合わせる。

1. `spine`
2. `torso_card`
3. `neck_card`
4. `face_base`

確認する点：

- 胴体の中心が `mihon` の中心線に合っている
- 首が胴体から自然につながっている
- 顔が首の上に正しく乗っている
- 全体の身長と横幅が見本に近い

胴体全体を動かすときは、可能なら個別カードではなく対応する論理ノードを動かす。カード単体を調整するときだけ、カード本体を動かす。

### 2-2. 頭・髪・帽子

次の順番で合わせる。

1. `face_base`
2. `hair_back_card`
3. `hair_front_side`
4. `hair_braised`
5. `hair_front_card`
6. `accessory_hair`
7. `hat`

確認する点：

- 後ろ髪が頭から浮いていない
- 前髪が目や口に不自然にかぶっていない
- 横髪と三つ編みが頭部につながっている
- 帽子が頭の中心からずれていない
- `mihon` と比べて頭だけ大きすぎたり小さすぎたりしない

髪のカードを拡大・縮小するときは、縦横比を崩さない。形状そのものを編集する必要がある場合は、配置確定後に別途判断する。

### 2-3. 腕と手

見ている人から見た左右と、キャラクターの左右を混同しない。

- 画面左：上げた黒い袖と手
- 画面右：赤い腕章のある袖と下側の手
- キャラクターの左腕は、正面表示では画面右側
- キャラクターの右腕は、正面表示では画面左側

調整順：

1. 上腕カードを肩に合わせる
2. 前腕カードを肘に合わせる
3. 手を手首に合わせる
4. 袖と手の重なり順を確認する

確認する点：

- 肩から腕が生えている
- 肘の位置で前腕が自然につながる
- 手首と手の向きが一致している
- 手が袖の下に埋もれすぎていない
- 赤い腕章が画面右側にある
- 上げた手の大きさが見本と大きく違わない

腕はカード全体を無理に伸縮させるより、上腕・前腕・手をそれぞれ合わせる。関節位置の見た目を最優先する。

### 2-4. 顔のパーツ

最後に顔を合わせる。

調整順：

1. 白目
2. 黒目
3. ハイライト
4. 上まぶた・下まぶた
5. 眉
6. 口

確認する点：

- 左右の目の高さがそろっている
- 黒目が白目の中央から大きく外れていない
- ハイライトが黒目から外れていない
- まぶたの線が目から浮いていない
- 眉が前髪に埋もれすぎていない
- 口が顔の中心線から外れていない

目の左右は、画面上の左右ではなくキャラクター側の左右で管理する。名前を変更して左右を修正しない。

## 3. 目パチとシェイプキー

目パチはボーンでは動かさない。目ごとの `blink` シェイプキーで、開いた状態から閉じた状態へ変化させる。

目パチの作業は、顔の位置・大きさを確定した後に行う。配置が決まる前に閉じ方を調整すると、あとで目を移動したときに閉じた形がずれる。

### 人間が確認・調整するもの

後工程のツールが `Basis` と `blink` を用意した後、次を確認する。

1. `blink` の値を1.0にする
2. 正面ビューで左右の目を確認する
3. 上まぶたの線が自然な閉じ目の形になるよう調整する
4. まぶたの塗りが白目・黒目を隠せているか確認する
5. 黒目やハイライトが閉じたまぶたからはみ出していないか確認する
6. 左右で閉じる高さや角度が極端に違わないか確認する
7. `blink` を0.0に戻し、開いた状態が元の見た目に戻ることを確認する

必要であれば、左右の `blink` シェイプキーを個別に微調整する。左右を完全に同じ形にする必要はないが、通常の目パチでは同じタイミングで閉じる。

### 目パチで人間がしないこと

- 目パチ用のボーンを作らない
- `Basis` の形を直接変更しない
- 黒目やハイライトを手で毎フレーム動かさない
- シェイプキーのキーフレームを手で大量に作らない
- 目パチ用のJSONを手入力しない

開閉アニメーションのキー、左右の同期、GLBへのシェイプキー出力、`animation.json` の `blink` チャンネル設定は後工程で行う。

### 現在の仮実装について

現在のファイルにある `blink` は、まぶたカードを単純に縦方向へ圧縮した仮のシェイプキーである。これは動作確認用として残してよいが、最終版では閉じ目の線と塗りが白目を自然に覆う形へ置き換える。

目パチの最終形は、次の構成にする。

- 白目：通常は表示
- 黒目・ハイライト：通常は表示、閉じるときは隠れるかまぶたの塗りで覆う
- 上まぶたの線：`blink` で閉じ目の線へ変形
- まぶたの塗り：`blink` で目を覆う
- 左右の目：それぞれ `blink_l`、`blink_r` を持つ

この目パチ確認が終わってから、腕や髪の支点を登録する。

## 4. 支点を決める

配置が固まったら、動かすときの支点を決める。支点は「カードの中心」ではなく「関節が曲がる位置」に置く。

### 必須の支点

- `root`
- `pelvis`
- `neck`
- `head`
- キャラクター左肩・左肘・左手首
- キャラクター右肩・右肘・右手首

### 髪の支点

左右それぞれについて、必要に応じて次を決める。

- 髪の根元
- 髪の中間
- 髪の先端

髪は根元を頭に固定し、中間と先端だけを揺らす。髪全体を一本のボーンで動かそうとしない。

### 支点の置き方

支点は次の位置に置く。

- 肩：胴体と上腕が接する中心
- 肘：上腕と前腕が接する中心
- 手首：前腕と手が接する中心
- 首：首カードと顔の接続部
- 頭：首から頭が回転する中心
- 髪の根元：髪が頭部から出る位置

支点はカードの外側に置かない。関節の内部、または接続部分の中央に置く。

## 5. 支点を登録する

支点用のEmptyを作る場合は、`Kanshu_Anchors` など専用コレクションにまとめる。

名前はキャラクター側の左右で付ける。

例：

```text
anchor_shoulder_l
anchor_elbow_l
anchor_wrist_l
anchor_shoulder_r
anchor_elbow_r
anchor_wrist_r
anchor_neck
anchor_head
anchor_hair_l_root
anchor_hair_l_mid
anchor_hair_l_tip
anchor_hair_r_root
anchor_hair_r_mid
anchor_hair_r_tip
```

支点用Emptyのルール：

- 表示は `Plain Axes` でよい
- レンダー対象にしない
- 画像カードの中身は編集しない
- 支点の位置だけを合わせる
- 支点をボーンに変換しない
- 支点同士を手で親子付けしない

最後のボーン生成と親子関係の設定は、支点を読み取る後工程で行う。

## 6. 最終チェック

次を上から順番に確認する。

- 全身のシルエットが `mihon` と大きく違わない
- 頭・胴体・腕の大きさの比率が自然
- 赤い腕章が画面右側にある
- 両手が袖から自然につながっている
- 髪が頭から浮いていない
- 帽子が頭の上に正しく乗っている
- 目・眉・口が顔の中心からずれていない
- 各パーツの前後関係が崩れていない
- 支点が関節の中心にある
- 仮ボーンのポーズを配置に焼き付けていない
- オブジェクト名と親子関係を変更していない
- トランスフォームを適用していない

問題がなければ、フレーム1などの静止状態で保存する。

## 7. 作業完了時の連絡

次の内容を伝えれば、後工程へ渡せる。

```text
看守2.5Dの配置調整完了。
支点の配置完了。
保存先：C:\works\2.5D\asset\model_kanshu\kanshu_2_5d_authoring.blend
目立つ未修正箇所：なし／（箇所を書く）
```

この後の作業では、Blenderの配置と支点を読み取り、最小構成のリグを生成してから、`character.json`、`animation.json`、GLB、Atlasをまとめて書き出す。

## 人間がやらない作業

以下は人間の手作業にしない。

- ボーンを一本ずつ作る
- ボーン名を手で合わせる
- JSONの座標を手入力する
- GLBを手で書き出して差し替える
- Atlasの座標を手で修正する
- 再ビルドのたびにカードを配置し直す

これらは、配置と支点が確定した後の自動処理にする。
